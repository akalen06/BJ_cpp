# C++ OOP Blackjack

Dit is mijn C++ Object Oriented Programming (OOP) Blackjack project, gespeeld in de console. Het spel ondersteunt meerdere menselijke spelers en CPU-spelers, met een eenvoudige inzet/credits-logica per ronde. [web:8][file:3]

## Build & Run

Het project is opgezet als een standaard C++ console-applicatie:

- Open de projectmap in je IDE (bijvoorbeeld Visual Studio / CLion / VS Code met C++-tooling). [web:13][web:19]
- Build de oplossing / het project.
- Run de gegenereerde executable; het spel start direct in de terminal/console. [web:13][web:19]

Er zijn geen extra libraries nodig buiten de standaard C++ STL.
